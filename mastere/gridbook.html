GridBook Architecture Souveraine

Plateforme de pari full-stack auto-hébergée sur Proxmox — architecture microservices, sécurisation Cloudflare, backend FastAPI et frontend React.

Projet Lab

Présentation du projet

GridBook est une plateforme de pari sportif full-stack développée et auto-hébergée sur mon serveur Proxmox personnel. Le projet couvre l'ensemble de la chaîne technique : virtualisation, containerisation, développement backend/frontend, sécurisation et monitoring.

L'objectif principal est d'explorer l'architecture microservices dans un environnement souverain — sans dépendance à des services cloud tiers. Sécurisé via Cloudflare Tunnel pour exposer les services sans ouvrir de ports directs.

Architecture

Architecture Technique

Virtualisation

Proxmox VE héberge des VMs Linux Ubuntu dédiées — une VM par service principal pour l'isolation.

Containerisation

Docker Compose orchestre les services applicatifs — backend, frontend, BDD et reverse proxy.

Sécurisation

Cloudflare Tunnel assure l'exposition publique sans ouvrir de ports — WAF, DDoS protection inclus.
